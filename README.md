# Pizzería Mamma Mía - Hito 2

Proyecto desarrollado en React (Vite) aplicando los conceptos de estados de componentes, eventos y manejo de formularios con validaciones, en el marco de la Academia de Talentos Digitales (Desafío Latam).

## 🚀 Funcionalidades del Hito 2
- **Formulario de Registro (`Register`):**
  - Campos obligatorios para Email, Contraseña y Confirmación de contraseña.
  - Validación de campos vacíos.
  - Validación de longitud mínima de contraseña (6 caracteres).
  - Validación de coincidencia entre contraseña y confirmación.
  - Alertas informativas de éxito o error en la autenticación.

- **Formulario de Login (`Login`):**
  - Campos obligatorios para Email y Contraseña.
  - Validación de campos vacíos y longitud mínima de contraseña de 6 caracteres.
  - Alertas de éxito o error al intentar iniciar sesión.

- **Navegación y Rutas:**
  - Configuración de rutas mediante `react-router-dom` para alternar entre componentes de manera dinámica.

## 🛠️ Tecnologías Utilizadas
- React (Vite)
- React Router DOM
- Bootstrap 5.3.3
